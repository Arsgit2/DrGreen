# 🚀 Руководство по улучшенному обучению модели

## ✅ Что было улучшено

### Основные проблемы предыдущего обучения:
1. **Неправильное объединение классов** - `train_transfer_ft.py` не объединял похожие классы из разных датасетов
2. **Низкая точность** - модель достигала только ~3% accuracy
3. **Неоптимальные гиперпараметры** - слишком низкий learning rate, недостаточно эпох

### Улучшения в `train_improved.py`:
1. ✅ **Правильное объединение классов** - использует `UnifiedDataset` с нормализацией имен
2. ✅ **Pretrained веса ImageNet** - использует предобученные веса для лучшей инициализации
3. ✅ **Оптимальные гиперпараметры**:
   - Learning rate: 1e-4 (вместо 1e-5)
   - Batch size: 32 (вместо 8)
   - Weight decay: 1e-4
   - Learning rate scheduler с уменьшением при плато
4. ✅ **Улучшенные аугментации** - больше разнообразия в данных
5. ✅ **Early stopping** - останавливает обучение при отсутствии улучшений
6. ✅ **Gradient clipping** - для стабильности обучения
7. ✅ **Балансировка классов** - веса классов для борьбы с дисбалансом

## 📋 Запуск обучения

### Быстрый запуск (рекомендуемые параметры):
```bash
cd backend
python train_improved.py --pretrained --fine-tune --epochs 50 --batch-size 32
```

### Или используйте скрипт запуска:
```bash
cd backend
python start_training.py
```

### Параметры по умолчанию:
- `--pretrained` - использовать веса ImageNet (рекомендуется)
- `--fine-tune` - обучать все слои (рекомендуется)
- `--epochs 50` - количество эпох
- `--batch-size 32` - размер батча
- `--lr 1e-4` - learning rate
- `--weight-decay 1e-4` - weight decay
- `--early-stop-patience 10` - терпение для early stopping

### Для слабых GPU (меньше памяти):
```bash
python train_improved.py --pretrained --fine-tune --epochs 50 --batch-size 16
```
