## 📋 Как это работает

1. **При инициализации `PlantDiseasePredictor`:**
   - Загружаются классы из `model/class_names.json` (если существует)
   - Если файла нет, классы загружаются из датасетов через `UnifiedDataset`
   - Создается ResNet18 модель с правильным количеством классов
   - Пытается загрузить обученные веса из файлов моделей

2. **При предсказании:**
   - Изображение предобрабатывается (resize 224x224, нормализация)
   - Пропускается через обученную ResNet18 модель
   - Возвращается название болезни и уверенность

## ⚠️ Важные замечания

1. **Точность модели:** Согласно отчетам оценки, текущие модели имеют низкую точность (~3%). Это может быть связано с:
   - Несовпадением классов между датасетами
   - Проблемами в процессе обучения
   - Недостаточным количеством данных для некоторых классов

2. **Пути к файлам:** Все пути настроены относительно корня `backend/`

3. **Совместимость:** Код обратно совместим - если модель не загрузится, будет использована ненастроенная модель (с предупреждением)

## 📝 Использование

Модель автоматически загружается при создании `PlantDiseasePredictor`:

```python
from app.ml import PlantDiseasePredictor

predictor = PlantDiseasePredictor()
result = predictor.predict("path/to/image.jpg")
print(f"Болезнь: {result['disease']}, Уверенность: {result['confidence']:.2f}")
```
