# 🔧 Автоматическая коррекция предсказаний

## ✅ Что добавлено

Добавлена интеллектуальная система коррекции предсказаний, которая автоматически различает **дырки** (повреждения вредителями) и **пятна** (болезни) на листьях.

## 🎯 Как это работает

### 1. Анализ структуры изображения
Модель анализирует изображение и определяет:
- **Дырки (holes)**: Сквозные отверстия в листьях (характерно для вредителей)
  - Обнаруживаются по темным областям с четкими краями
  - Обычно круглой/овальной формы
  - Виден фон через отверстие
  
- **Пятна (spots)**: Поражения ткани без сквозных отверстий (характерно для болезней)
  - Обнаруживаются по цветовым изменениям (коричневые, желтые, черные)
  - Имеют цвет (насыщенность)
  - Не являются сквозными отверстиями

### 2. Автоматическая коррекция

**Если обнаружены дырки, но модель предсказала пятнистость:**
- ✅ Модель автоматически корректирует предсказание на класс вредителей
- ✅ Выбирает наиболее вероятный класс из: `Tomato_Spider_mites_Two_spotted_spider_mite` или `Tomato_two_spotted_spider_mites_leaf`

**Если обнаружены пятна (без дырок), но модель предсказала вредителей:**
- ✅ Модель автоматически корректирует предсказание на класс пятнистости
- ✅ Выбирает наиболее вероятный класс из: `Tomato_Bacterial_spot`, `Tomato_Septoria_leaf_spot`, и т.д.

## 📊 Что возвращается в ответе

Теперь метод `predict()` возвращает дополнительную информацию:

```python
{
    "disease": "Tomato_Spider_mites_Two_spotted_spider_mite",  # Скорректированное предсказание
    "confidence": 0.85,
    "correction_applied": True,  # Была ли применена коррекция
    "correction_reason": "Обнаружены дырки в листьях (не пятна). Скорректировано с 'Tomato_Bacterial_spot' на 'Tomato_Spider_mites_Two_spotted_spider_mite'",
    "structure_analysis": {
        "has_holes": True,  # Обнаружены ли дырки
        "has_spots": False,  # Обнаружены ли пятна
        "holes_count": 15,  # Количество дырок
        "spots_count": 0  # Количество пятен
    },
    "all_probabilities": {...}  # Все вероятности классов
}
```

## 🎯 Примеры работы

### Пример 1: Дырки в листьях
- **Модель предсказала**: `Tomato_Bacterial_spot` (95%)
- **Анализ структуры**: Обнаружены дырки (15 штук)
- **Коррекция**: ✅ Автоматически изменено на `Tomato_Spider_mites_Two_spotted_spider_mite`
- **Результат**: Правильный диагноз - вредители, не бактерии

### Пример 2: Пятна на листьях
- **Модель предсказала**: `Tomato_Spider_mites` (80%)
- **Анализ структуры**: Обнаружены пятна (без дырок)
- **Коррекция**: ✅ Автоматически изменено на `Tomato_Bacterial_spot`
- **Результат**: Правильный диагноз - болезнь, не вредители

## ⚙️ Технические детали

### Алгоритм обнаружения дырок:
1. Адаптивная пороговая обработка для выделения темных областей
2. Морфологические операции для очистки
3. Анализ контуров по размеру и форме (круглость)
4. Проверка интенсивности (дырки темные - виден фон)

### Алгоритм обнаружения пятен:
1. Цветовая сегментация (HSV) для коричневых, желтых, черных областей
2. Морфологическая обработка
3. Анализ контуров по размеру
4. Проверка насыщенности (пятна имеют цвет)

```
[INFO] Confidence скорректированного класса: 0.35
```

## 🎉 Результат

Теперь модель **автоматически исправляет** ошибки, когда путает:
- ❌ Бактериальную пятнистость (пятна) ↔ Дырки от вредителей
- ✅ Правильно определяет дырки → вредители
- ✅ Правильно определяет пятна → болезни

Это значительно повышает точность диагностики! 🚀
