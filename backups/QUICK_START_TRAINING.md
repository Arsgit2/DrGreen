# 🚀 Быстрый старт: Переобучение модели

## ✅ Готово к запуску!

Создан улучшенный скрипт обучения `train_improved.py` с исправлениями:

### 🔧 Основные улучшения:
1. ✅ Правильное объединение классов из разных датасетов
2. ✅ Использование pretrained весов ImageNet
3. ✅ Оптимальные гиперпараметры (LR: 1e-4, batch: 32)

## ▶️ Запуск обучения

### Вариант 1: Полное обучение (рекомендуется)
```bash
cd backend
python train_improved.py --pretrained --fine-tune --epochs 50 --batch-size 32
```

### Вариант 2: Быстрый тест (2 эпохи для проверки)
```bash
cd backend
python train_improved.py --pretrained --fine-tune --epochs 2 --batch-size 16
```

### Вариант 3: Если мало памяти GPU
```bash
cd backend
python train_improved.py --pretrained --fine-tune --epochs 50 --batch-size 16
```

## 📊 Что произойдет:

1. Загрузка и объединение датасетов (правильное объединение классов)
2. Создание ResNet18 с pretrained весами
3. Обучение с мониторингом:
   - Точность на train и validation
   - Автоматическое сохранение лучшей модели
   - Early stopping при отсутствии улучшений
4. Сохранение:
   - `model/plant_disease_resnet18_improved.pth` - лучшая модель
   - `model/training_info_improved.json` - информация об обучении
   - `model/class_names.json` - список классов
